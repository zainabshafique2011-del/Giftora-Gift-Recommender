# 🎁 Giftora AI

Giftora AI is an AI-powered web application that helps users discover thoughtful and personalized gift ideas for their loved ones. It also generates heartfelt greeting card messages, creative gift wrapping ideas, and surprise presentation suggestions based on the recipient, occasion, interests, and budget.

---

## 📌 Problem Statement

Choosing the perfect gift can be stressful and time-consuming. Many people struggle to find meaningful gift ideas and often don't know what message to write in a greeting card.

Giftora AI solves this problem by using Artificial Intelligence to generate personalized gift recommendations along with greeting card messages, wrapping ideas, and surprise presentation suggestions, making gift-giving easier and more memorable.

# 🤖 AI Feature

Giftora AI uses Artificial Intelligence to generate personalized gift recommendations based on the information entered by the user.

The AI considers:

- Recipient
- Relationship
- Occasion
- Interests
- Budget
- Additional notes

It then generates:

- Personalized gift recommendations
- Emotional greeting card message
- Gift wrapping ideas
- Surprise presentation ideas

# 🚀 How to Run the Project

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

## 2. Open the project

```bash
cd YOUR_REPOSITORY
```

## 3. Install dependencies

```bash
npm install
```

## 4. Create a `.env` file

```env
GROQ_API_KEY=YOUR_GROQ_API_KEY
```

## 5. Start the development server

```bash
npm run dev
```

The application will run at:

```
http://localhost:8080
```
